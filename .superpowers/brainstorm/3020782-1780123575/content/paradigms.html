唯一入口长成什么样?三种 Agent-First 交互范式

定调已定:agent 是入口,报表是它的产物之一。剩下的核心分叉是 —— 「对话」和「产物画布」谁是主轴。点一个你最有共鸣的。

💬 对话主轴
问：各项目本月利润?
→ 已生成右侧报表 ↗
追问：按区域拆
输入…
📌 活产物画布
[ 存为卡片 ] [ 钉到看板 ]

① 对话 + 活产物画布 推荐

左边是连续对话(分析的脉络),右边画布钉着「当前产物」,追问时产物原地演化。报表 = 对话产出的 artifact,天然一键沉淀。追问/下钻/闭环全打通。

🗂 看板工作台主轴
🤖 选中图表问 agent：为什么跌了?

② 看板画布 + 环境化 Agent

工作台(现在的 BI)是主体,agent 是悬浮在万物之上的一层:选中任何图表/数字就能让它解释、下钻、对比。改造小、保留现有投入。但 agent 偏「辅助」,和「agent 即入口」的定调略冲。

🔍 你想了解什么?
澄清:哪个时间段?本月
SELECT … FROM 报花 ✓溯源
↘ 追问区域存为报表

③ 单框 Omnibox + 渐进展开

一个大搜索框(像 Perplexity)。输入后逐层流式展开:澄清芯片 → SQL 预览+溯源 → 结果 → 推荐追问 → 存报表。冷启动最低、最「一个入口」。但复杂多产物分析在线性流里容易挤。

我的倾向:以 ① 为骨架,把 ③ 的 omnibox 当作①的空状态(冷启动那一刻就是一个大框),把 ② 的环境化能力(选中即问)作为画布上的增强。三者其实能合成一个,但主轴必须二选一:对话 还是 画布。可多选,告诉我你的直觉。
